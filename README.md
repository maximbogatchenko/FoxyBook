# 📚 FoxyBook

Modern Android reader for FB2, EPUB and MOBI.

![Android](https://img.shields.io/badge/Android-8.0%2B-green)
![Kotlin](https://img.shields.io/badge/Kotlin-100%25-purple)
![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-Latest-blue)

## ✨ Features

* 📖 Comfortable reading interface
* 📚 Support for FB2 books
* 📘 Support for EPUB books
* 🌐 HTML chapter rendering
* 🔍 Fast navigation through chapters
* 🎨 Modern Material Design 3 UI
* ⚙️ Flexible reading settings
* 💾 Local library management
* 🚀 Built with Kotlin and Jetpack Compose

## 🛠 Technology Stack

* Kotlin
* Jetpack Compose
* Material 3
* Kotlin Serialization
* DataStore
* Coil
* Jsoup
* OkHttp

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/maximbogatchenko/FoxyBook.git
```

Open the project in Android Studio and run it on a device or emulator.

## 📦 Requirements

* Android 9.0 (API 28+) or newer
* Android Studio Hedgehog or newer

## 🎯 Project Goal

FoxyBook aims to provide a clean, fast and modern reading experience for Android users while supporting popular e-book formats.
